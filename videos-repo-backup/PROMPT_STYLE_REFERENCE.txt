GENERAL OBSERVATIONS FROM THESE EXAMPLES
----------------------------------------
- Starts: "MS Paint painted flat clean style , white background. Scene : ..."
  (some omit "white background" when scene has its own background clause)
- "Scene : " prefix before the scene description.
- Character refs inside scenes: "provided in image 1 / image 2 / as reference".
- New characters inside a scene: "create it", "not provided , so create it".
- Text cards: 'a leader line to text as written by hand but clean , reads "TEXT"'
  (earlier videos sometimes "as written by hand, reads"). Text in single quotes
  inside the double-quoted prompt. Key words colored red (e.g. STORM red).
- Icon cards: "with a icon of <thing> under it" (rain cloud, mammoth).
- Env scenes end with: "background: <concrete details>". Always sky mentioned
  outdoors (grey sky, sky). No sun/moon/stars unless asked.
- Filler words that make images look simple: "simple ..." — user banned these.
- Character masters: name only (with "stickman/stick figure") + clothing. NO
  expression, NO hands, NO action detail at character-master time.
